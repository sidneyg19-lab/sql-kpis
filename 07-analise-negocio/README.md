# 🔎 Análise de Negócio — SQL

Esta seção apresenta consultas SQL utilizadas para transformar dados operacionais em informações úteis para **análise de processos, identificação de gargalos e apoio à tomada de decisão**.

Os cenários são genéricos e representam situações comuns encontradas em sistemas ERP e processos empresariais.

---

## 🎯 Objetivos

As análises desta seção permitem identificar:

- ⏱️ Tempo médio das etapas de processos
- ⚠️ Processos com atraso
- 🔄 Volume por status
- 👥 Distribuição de atividades por responsável
- 📊 Indicadores de desempenho operacional
- 🚧 Gargalos em fluxos de aprovação
- 📈 Evolução dos processos por período

---

## 📂 Consultas

| Arquivo | Descrição |
|---|---|
| `gargalos-processo.sql` | Identifica etapas com maior tempo de processamento |
| `volume-por-status.sql` | Consolida processos de acordo com seus status |
| `sla-processos.sql` | Analisa cumprimento de prazos e SLA |
| `desempenho-processos.sql` | Consolida indicadores de desempenho operacional |

---

## 🧠 Competências demonstradas

- Análise de processos
- Levantamento de indicadores
- Identificação de gargalos
- Regras de negócio
- SQL aplicado ao negócio
- KPIs operacionais
- Análise de SLA
- Apoio à tomada de decisão

---

## 💼 Aplicação

As consultas podem apoiar atividades de:

- análise de requisitos;
- análise de negócios;
- melhoria de processos;
- acompanhamento operacional;
- definição de indicadores;
- identificação de oportunidades de melhoria;
- validação de regras de negócio.

> Os dados e estruturas apresentados são genéricos e possuem finalidade demonstrativa.
