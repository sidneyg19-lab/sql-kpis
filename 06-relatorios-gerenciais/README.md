# 📊 Relatórios Gerenciais — SQL KPIs

Esta pasta reúne consultas SQL voltadas à criação de **relatórios gerenciais, indicadores consolidados e apoio à tomada de decisão** em ambientes ERP.

Os exemplos utilizam estruturas e dados genéricos para representar cenários encontrados em processos empresariais.

---

## 🎯 Objetivos

As consultas desta seção permitem analisar indicadores como:

- 📈 Visão consolidada dos principais KPIs
- 💰 Indicadores financeiros por período
- 🛒 Indicadores de compras e suprimentos
- 🏗️ Indicadores de projetos
- 📄 Indicadores de contratos
- 🧾 Indicadores fiscais
- 📅 Evolução mensal dos resultados
- 🎯 Comparação entre períodos

---

## 📂 Consultas

| Arquivo | Descrição |
|---|---|
| `dashboard-executivo.sql` | Consolida indicadores estratégicos para visão executiva |
| `kpis-mensais.sql` | Analisa a evolução mensal dos principais indicadores |
| `resumo-por-area.sql` | Consolida resultados por área de negócio |
| `comparativo-periodos.sql` | Compara indicadores entre períodos |

---

## 🧠 Conceitos aplicados

As consultas demonstram utilização de:

- `SELECT`
- `INNER JOIN`
- `LEFT JOIN`
- `GROUP BY`
- `CASE WHEN`
- `SUM()`
- `COUNT()`
- `AVG()`
- `COALESCE()`
- `DATE_FORMAT()`
- Subqueries
- Agregações
- Indicadores e KPIs

---

## 💼 Aplicação

Essas consultas podem servir como base para:

- dashboards gerenciais;
- relatórios de acompanhamento;
- análise de desempenho;
- acompanhamento de metas;
- identificação de desvios;
- apoio à tomada de decisão;
- integração com ferramentas de Business Intelligence.

> Os dados e estruturas apresentados são genéricos e possuem finalidade demonstrativa.
